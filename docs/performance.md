# 性能与包体积

## 本轮范围（2026-11-10）

保留 Go + MyGo、SQLite 持久化、内存搜索及独立插件架构。本轮先处理已确认的大量分配和重复工作：

- [x] 按配置差异应用设置。语言、外观、更新等无关修改不重建文件索引，不重启音量钩子或重复设置开机启动；Everything 连接配置与本地索引配置分开判断。
- [x] 个人规则独立发布。使用次数、别名、固定和隐藏更新只替换单条不可变规则，不再复制整个索引；文件刷新复用规则单元，避免旧扫描的规则快照覆盖最新使用记录。批量导入与重置仍使用 `UpdateProfiles`。
- [x] 搜索复用排序键，Top-K 堆保存轻量候选项，最后才生成完整结果。匹配字段保持连续，无个人别名时在命中后读取规则，减少无命中扫描的额外开销。
- [x] 索引替换复用旧 `byID` 与未变化的拼音、副标题和别名，移除重复的去重 map。
- [x] 背景图片在工作线程读取、解码和缓存，按请求代次拒绝过期结果；调节透明度、蒙版或模糊不重复解码或重新设置相同的原生材质。非 JPEG 大图按窗口与 DPI 缩小；JPEG 保留 MyGo 的 EXIF 自动转正解码，目前未降采样。
- [x] 隐藏面板取消查询，重新显示时按当前状态刷新；隐藏时索引变化不再触发插件等搜索。
- [x] 默认关闭每 2 秒一次的内存采样与 UI 更新，诊断时设置 `FL_DEBUG_MEMORY=1`。
- [x] 文件索引任务跟随配置与退出取消，取消后不写回部分扫描结果；索引配置相同时复用已有监听。原有 750ms 文件事件防抖保留。
- [x] 原始品牌图仅作生成源，发布程序携带 256px 应用图标及预处理的 48px 托盘图标，启动时不再缩放原图或计算透明边缘。

## 可复现基准

`internal/core/search/engine_bench_test.go` 使用 1,000 / 10,000 / 100,000 条固定模拟文件，25% 中文标题、75% 混合大小写英文标题，返回前 20 条。覆盖高命中英文、中文、无命中、单条规则更新和内容不变的索引替换。

```powershell
$env:CGO_ENABLED = '0'
go test ./internal/core/search -run '^$' -bench '^BenchmarkEngine$' -benchmem -benchtime=400ms -count=3
```

对照版本为优化前 `78549c7` 的源码归档，复制同一份 benchmark 文件后运行；两版顺序执行，避免构建或其他测试并行干扰。环境为 Windows amd64、Go 1.27.3、AMD Ryzen 7 5800H，默认 16 个逻辑处理器。

基准结果以每组多轮 `ns/op` 的中位数与 `B/op` 表示，不是输入到首帧延迟，也不是 P95；小样本耗时受机器负载和频率影响。原始结果保存在本地 Git 忽略的 `build/perf-audit/` 下。

| 操作 | 优化前 | 优化后 | 分配变化 |
| --- | ---: | ---: | --- |
| 1 万条英文高命中搜索 | 2.30ms | 0.56ms | 386.8KiB → 7.4KiB |
| 10 万条英文高命中搜索 | 22.86ms | 9.55ms | 3.47MiB / 150,234 次 → 7.4KiB / 32 次 |
| 10 万条中文搜索 | 15.23ms | 9.83ms | 30.5KiB → 7.4KiB |
| 10 万条无命中搜索 | 9.88ms | 9.42ms | 均为 64B / 3 次，耗时保持同量级 |
| 10 万条中更新一条使用记录 | 14.01ms | 0.37µs | 42.73MiB → 144B |
| 10 万条内容不变的索引替换 | 195.53ms | 67.09ms | 112.80MiB → 49.12MiB |

高命中英文查询分配下降约 99.8%，无变更索引替换分配下降约 56.5%。这些数据只代表上述固定数据集；不据此推算用户环境的 CPU、冷启动或总内存改善比例。

## 同参数包体积对照

从优化前源码归档和本轮源码分别使用 MyGo 0.7.4 构建未签名 `windows/amd64` 发布包，版本均为 `0.1.0`。归档采用 `scripts/portable` 相同的单 EXE tar 头与 Go 默认 gzip 配置，不包含旁置 SQLite DLL。

| 产物 | 优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| EXE | 19,758,080B（18.84MiB） | 18,778,624B（17.91MiB） | 979,456B，约 4.96% |
| 单 EXE tar.gz | 8,799,739B（8.39MiB） | 7,994,665B（7.62MiB） | 805,074B，约 9.15% |

本轮没有覆盖现有正式签名产物，也没有发布或部署；正式版本的更新配置、版本信息和签名构建仍需按发布流程验证。包体积结果对应本轮提交前的构建，后续版本的 VCS 信息或工具链变化可能引入少量差异。

## 验证

- `CGO_ENABLED=0`：`go build ./...`、`go vet ./...`、`go test ./...`、`go tool mygo vet .`、`go tool mygo i18n check .` 通过。
- `CGO_ENABLED=1`：搜索并发刷新、单条/批量个人规则更新、Top-K 排序、背景缓存/EXIF、无关设置修改和取消扫描的针对性 race 检查通过。
- Top-K 与完整排序对照覆盖大小写、兼容字符、中文/拼音、别名、固定/隐藏、多 token 和同标题的稳定排序。
- 背景缓存测试覆盖文件替换、尺寸上限、取消和 JPEG EXIF 自动转正；扫描取消测试确认数据库条目与回调不被部分结果替换。
- 隔离 MyGo 发布构建通过；资源重复生成的 SHA-256 一致，已检查生成图标。没有运行用户日常使用的启动器或访问个人配置、数据库。
- 真实材质合成、冷启动、热键首帧和用户配置下的内存占用仍未实机验收。

## 资源生成

品牌原图位于 `assets/brand/source.png`，不嵌入 EXE。修改原图后运行：

```powershell
go generate ./internal/bundled
```

生成器为 `scripts/icons`，输出 `internal/bundled/icon.png` 与 `tray.png`，均需提交。应用图保留原设计，托盘图沿用原运行时的透明边缘处理。不要在运行时重新缩放原图。

发布构建继续使用固定版本 MyGo 的 `-s -w`、`-trimpath`、生产模式与 `mygo_noinspector`；未引入 UPX、CGO 依赖或预览版工具。主程序继续不携带官方插件。
