# 搜索触发与 Everything

## 固定前缀和工具设置

“设置 → 搜索与工具”集中管理 9 个内置工具，按计算与实用工具、日期与时间分组，以列表逐行直接编辑。顶部可按工具名称、固定前缀或触发词筛选；编辑匹配字段时保留当前行，直到焦点离开。第三方插件仍在“插件”页管理。

每行提供：

- **启用**：关闭后不执行该工具，显式调用会说明已关闭。
- **固定触发前缀**：原样匹配输入开头，优先于普通搜索参与选项。计算器默认是 `=`，`=1+2` 得到 `3`；`1+2`、`2026-11-10` 不产生计算结果。可改为其他前缀，旧前缀随后失效。
- **触发词**：逗号分隔的完整关键词，不做模糊匹配；也用于显式 `tool` 调用。UUID 默认 `uuid, guid`，可改为 `uid`。
- **参与普通搜索**：没有固定前缀时生效。关闭后不在普通输入中调用；开启时按触发词调用，计算器还会自动识别算式。

固定前缀不能包含空白。触发词不能与范围保留词、其他工具或启用的站点冲突；修改工具触发配置、启用插件时还检查已安装启用插件的关键词。历史已有的插件/工具重叠在未修改相关配置时继续保留。

| 输入 | 默认行为 |
| --- | --- |
| `=1+2` | 只计算，不搜索应用、文件或插件 |
| `uuid` | 只生成 UUID |
| `tool` | 列出启用的工具；回车填入调用入口 |
| `tool calc 1+2` | 显式计算，不受普通搜索参与开关影响 |
| `tool uuid` | 显式生成 UUID |
| `file uuid` | 只搜索文件，不生成 UUID |
| `app =1+2` | 只搜索应用，不计算 |

### 工具一览与多格式结果

内置工具只保留启动器里高频、开箱即用的日常值。结果按格式逐行列出，上下键选择、回车复制所选格式；第一行是默认格式，保持默认选中。

| 输入 | 依次列出 |
| --- | --- |
| `uuid` | 标准小写、无横线、大写、大写无横线、带花括号 `{…}`（注册表 / COM） |
| `uuid 5` | 同上五种格式，每行显示第一个，回车按“每行一个”复制全部（1–20 个） |
| `time` / `现在` | `15:04:05`、`2026-11-14 15:04:05`、`15:04`、`3:04:05 PM`、精确到毫秒、ISO 8601（含时区）、UTC |
| `date` / `今天` | `2026-11-14`、`2026/11/14`、`20261114`、`2026年11月14日`、`2026年11月14日 星期六`、`Saturday, November 14, 2026` |
| `date +3d`、`date 2026-01-31 +1m -1w` | 日期算术，省略日期时从今天算，可连写多步；月份不足时落到月末；格式同上 |
| `timestamp` | 当前 Unix 秒、毫秒 |
| `timestamp 1794652200`、`time 1794652200` | 本机时间（标明时区）、UTC、ISO 8601，以及毫秒值；13 位按毫秒识别 |
| `timestamp 2026-11-14 18:30` | 该时刻（按本机时区）的 Unix 秒、毫秒；也接受 `/` 分隔与 RFC 3339 |
| `week`、`week 2026-01-01` | ISO 周 `2026-W01`、周数、该周周一至周日 |
| `days 2026-12-01`、`days 2026-01-01 2026-03-01` | 距今天数或两日期相差天数（未来为正），满一周时再给“几周几天” |
| `rand 1-100` | 区间内随机整数（含端点） |
| `pass 16` | 含符号、仅字母数字、仅数字三种随机密码（4–64 位，去掉易混字符） |

日期参数接受 `2026-11-14`、`2026/11/14`、`20261114` 以及 `today`/`tomorrow`/`yesterday`（今天 / 明天 / 昨天）。

动作面板里的“重新生成”保留原来的区间、长度和个数：UUID 各行共用同一个值，会一起换新；密码各行是独立随机值，只换选中那一行。日期各行都可复制当天零点的时间戳。

单位换算、颜色转换和 `b64`/`unb64`/`urlencode`/`urldecode` 已从内置工具移除：它们是低频或开发类转换，`tool convert …` 这样的长命令也不适合搜索框的主入口。旧配置里的这些条目在读取时自动清理。编码解码、JSON、正则、摘要和颜色由官方“开发工具”插件提供，关键词因此不再被内置工具抢先。

显式 `tool` 入口不受固定前缀限制，但仍遵守工具启用开关。工具稳定 ID（如 `calc`、`uuid`）也可以在 `tool` 后使用，不随自定义别名变化。旧配置里关闭的计算器保持关闭。

路由在分发搜索前完成，命中固定前缀或直接工具关键词时，只调用工具来源。普通输入仍并发查询符合范围的来源，本地内存搜索不增加等待。

## Everything

在“设置 → 文件”的 Everything 卡片中开启连接器：

- **未运行时自动后台启动**：默认开启，仅在需要查询 Everything 时启动。使用官方 `Everything.exe -startup` 参数，不弹搜索窗口。
- **程序位置**：留空自动检测。复用应用发现中的 EXE/快捷方式目标，再检查注册表、常见安装位置与 PATH；便携版可以手动选择 EXE。不会扫描整块磁盘寻找程序。
- **后台启动并连接**：手动重试，不受自动启动开关和失败退避限制。
- **打开 Everything**：正常打开应用窗口，与后台连接分开。

连接状态区显示尚未连接、正在启动、已连接或失败原因。IPC 窗口可用表示已连接；这不保证全部磁盘索引已经加载完毕，实际查询失败会显示查询错误。当前连接器使用默认实例，命名实例需要调整 Everything 配置或使用默认实例。

多个搜索共用一次启动任务；输入取消不会杀死正在启动的 Everything。连接成功后等待中的搜索只继续执行仍有效的查询。启动等待最多 10 秒，失败后自动重试退避 15 秒，修改路径或发现新的程序位置可立即重试。程序退出后，下一次需要它的搜索可以再次启动。

Everything 查询单独合并 100ms 内的连续输入，排队请求执行前检查取消状态。FluentLauncher 退出时不结束 Everything，也不安装服务、修改其开机启动项或重建它的索引。

“重建本地目录索引”只影响 FluentLauncher 自身配置的目录，与 Everything 卡片分开。

## 验证

回归测试覆盖固定前缀、自定义别名、工具关闭、普通搜索参与开关、范围优先、外部来源零调用、配置重载、冲突检查、Everything 合并启动/取消/退避以及多语言设置界面。

导出三语深浅主题的内存渲染预览：

```powershell
$env:FL_SEARCH_ARTIFACT_DIR = "$PWD/build/search-previews"
go test ./internal/app -run '^TestSearchSettingsLayouts$' -count=1
Remove-Item Env:FL_SEARCH_ARTIFACT_DIR
```

默认测试不读取个人设置、不启动实际 Everything，也不操作桌面。真实客户端的进程启动、IPC 和 Windows 权限状态需单独联调。本轮真实客户端探测返回“未找到 Everything”，因此尚未完成实际客户端冷启动验收；模拟并发启动与取消测试已通过。

本机安装好客户端后，可显式运行真实查询测试。便携版可设置完整路径；测试会按需后台启动客户端，并保留其运行：

```powershell
$env:FL_TEST_EVERYTHING_LIVE = '1'
$env:FL_TEST_EVERYTHING_PATH = 'D:\Tools\Everything\Everything.exe'
go test ./internal/winapi/everything -run '^TestEverythingLiveIntegration$' -count=1 -timeout=25s -v
Remove-Item Env:FL_TEST_EVERYTHING_LIVE, Env:FL_TEST_EVERYTHING_PATH
```
