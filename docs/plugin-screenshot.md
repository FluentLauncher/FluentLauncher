## 已确认的交互

- 触发词：`截图` / `screenshot` / `snap` / `截屏`；区域截图和区域截图并贴图可绑定宿主快捷键。
- 先隐藏启动器并等待桌面合成，再冻结虚拟屏幕；在快照上拖选、移动、调整选区，复制 / 保存 / 贴图，Esc 或右键取消。取消不修改剪贴板。
- 贴图用于覆盖下层画面后再次截图。默认保留已有贴图参与后续捕获；可通过插件配置关闭。截图工具条不参与捕获。
- 贴图按原位置和物理像素尺寸显示，完全不透明、置顶、多窗口、仅内存。默认外阴影，可由右键菜单关闭。
- 点击选中贴图后，方向键每次移动 1 个物理像素，Shift＋方向键移动 10 像素；仅在贴图有键盘焦点时生效，锁定后不允许拖动或微调。
- 右键菜单：复制、另存为、显示阴影、锁定位置、恢复原始大小、回到原始位置、隐藏、关闭；1.1.0 增加置顶 / 任务栏、透明度、大小预设、旋转镜像、文件操作和重置。复制与保存使用原始分辨率并包含旋转 / 镜像，不包含显示缩放、透明度或阴影。
- 搜索命令提供显示 / 隐藏 / 关闭全部贴图；隐藏仍保留图片，需要保活。关闭最后一张且无捕获任务后才可回收插件。
- 新贴图不主动抢走原应用焦点；用户点击后才能使用键盘微调。普通截图有输出选择，直接贴图入口确认选区后生成贴图。
- 只在用户明确启动截图时捕获；不上传，不写截图历史。仅在主动文件打开 / 拖出时生成临时 PNG，正常退出尽力清理。配置写入 `%LOCALAPPDATA%\FluentLauncher\plugin-data\official.screenshot\settings.json`，与插件安装目录分离。

## 技术与验收

- Windows 11 x64，Go + Win32 / GDI，无 MyGo、WebView 或 Visual Studio 依赖；SDK 仍仅依赖标准库。
- GUI 专用锁定线程与消息循环，RPC 启动任务后立即返回；耗时编码和磁盘操作在后台执行。
- PER_MONITOR_AWARE_V2，统一物理像素坐标；覆盖负坐标与混合 DPI 多显示器。选区窗口不能使用鼠标穿透样式。
- 异步失败在插件界面可见；复制 / 保存失败保留当前图片，允许重试。
- 检查超过宿主空闲期限仍保留贴图、隐藏可恢复、关闭可回收、重复捕获不叠加任务、禁用与退出关闭全部窗口。
- 检查贴图方向键与 Shift 步长、锁定、焦点切换、菜单操作、阴影开关、再次截图包含 / 排除贴图。
- 自动化与原生桌面验证分别记录；受保护内容、HDR 色彩与独占全屏兼容性不作未经验证的承诺。
